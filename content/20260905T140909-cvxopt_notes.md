	- A set $C \subseteq \R^n$ is an *affine set* if $\forall x, y\in C$

## Convex set
- Define a convex set
	- A set $C \subseteq \R^n$ is a *convex set* if $\forall x, y\in C,$
$$\theta y + (1 - \theta) x \in C, \theta \in [0, 1]$$
- Are all affine sets convex sets? If so why?
	- Yes. All affine sets are convex sets. Convex sets require every point on the line segment between two points to be in the set. Affine sets have **all the points on the line** in them. As the line segment is part of the line, every point on the line segment will be in the set, therefore making it convex.
- If a set is convex does it make it affine?
	- **No**.
