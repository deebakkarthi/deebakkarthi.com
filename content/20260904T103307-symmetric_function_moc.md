$\newcommand{N}{\mathbb{N}}$
For some function $F$, if the order of its arguments don't matter, then it is symmetric.

# Example
Let us take a function $F: \N \times \N \rightarrow \N$
if $F(x, y) = F(y, x), \forall x, y \in \N$, then it is *symmetric*
