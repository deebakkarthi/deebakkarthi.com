- The big end is at the top
- MSB comes first
- This is the natural way

Consider the data `0xDEADBEEF`

| Address       | Data   |
| ------------- | ------ |
| `0x0000.0000` | `0xDE` |
| `0x0000.0001` | `0xEA` | 
| `0x0000.0002` | `0xDB` |
| `0x0000.0003` | `0xEF` |
| `0x0000.0004` | `0xEF` |

- The opposite is [little endian](20260120T123337-little_endian.md)
