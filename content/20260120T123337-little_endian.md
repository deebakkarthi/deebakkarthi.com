- The little end is at the top
- LSB comes first

Consider the data `0xDEADBEEF`

| Address       | Data   |
| ------------- | ------ |
| `0x0000.0000` | `0xEF` |
| `0x0000.0001` | `0xEF` |
| `0x0000.0002` | `0xDB` |
| `0x0000.0003` | `0xEA` |
| `0x0000.0004` | `0xDE` |

- Opposite is [big endian](20260120T123730-big_endian.md)
