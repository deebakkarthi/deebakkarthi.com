# Literature on the best way to gauge formal verification coverage

- Let me first see the cited paper by these assertion generation papers which deal with coverage metrics
	- [baiAssertionForgeEnhancingFormal2025](baiAssertionForgeEnhancingFormal2025.md) cite [chocklerCoverageMetricsFormal2003](chocklerCoverageMetricsFormal2003.md) and [liCoverageDrivenFormalMethodology2019](liCoverageDrivenFormalMethodology2019.md)
		- [chocklerCoverageMetricsFormal2003](chocklerCoverageMetricsFormal2003.md) create a set of metrics that are analogous to coverage metrics used in simulation. They accomplish this mostly using mutations
		- [liCoverageDrivenFormalMethodology2019](liCoverageDrivenFormalMethodology2019.md) create a coverage sign off  plan that  uses 100% COI coverage along with few other metrics to sign off a design as correct.
