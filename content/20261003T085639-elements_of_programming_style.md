# Chapter 1
- Don't be too clever. Write for clarity. Your future self will thank you.
## Points to ponder
### 1.1) Comparison of matrix assignment operations and matrix arithmetic operations
- Regardless of the input size, the arithmetic operations are asymptotically larger than the assignment operations.
- So, for any program involving both, assignment will only account for about 10% of the total running time.
