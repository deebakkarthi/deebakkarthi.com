# Hyperspace separation Theorem
There is a small error from last class

if $A, B \subseteq \R^n$ are two **relative interior** disjoint sets then $\exists V \in \R^n, v\ne0, c\in\R$ such that

$$\langle v, x \rangle \le c \le \langle v, y \rangle$$

$$\mathbf{relint} = \{c \in C | B(x, r) \cup \mathbf{aff}~ C \subset C\text{ some }r > 0\}$$

![](../assets/Pasted%20image%2020260910112406.png)

Consider the above example, $B$ is just a line. It has no unit balls therefore no interior
$\mathbf{int}~ A \cap \phi = \phi$. So their interiors are disjoint. But we cannot separate them. 

To fix this we introduce *relative interior* where we calculate the interior relative to the the convex hull  of the set.

# Convex Function
$f: C \subset \R^n \rightarrow \R$ is convex if 
1. $C$ is a convex set
2. $f(\theta x + (1-\theta y)) \le \theta f(x) + (1 - \theta)f(y), \forall x, y \in \mathbf{dom}~f, \forall \theta \in [0, 1]$

![](../assets/Pasted%20image%2020260910113142.png)

Think of $\theta$ as parameter to move along the chord between $x$ and $y$.
This chord has to be above the function at all times

# Concave
A function $f$ is concave iff $-f$ is convex according to the definition from above.

# Why should $\mathbf{dom}~ f$ be convex?
That condition seems extraneous right? NO. Without that functions that are convex by nature won't be convex because of the domain

![](../assets/Pasted%20image%2020260910113635.png)

Consider the function $f(x) = \frac{1}{x^2}$. It is convex over $(0, \infty)$ and $(-\infty, 0)$
but not the union of both. Because the union is not a convex set.

Notice that the definition of concave also requires the domain to be a convex set. I don't think there are concave sets.

# Both convex and concave
- As the inequalities are not strict, it is possible for a function to be both convex and concave
- It implies that the function is affine and in fact this is a double-implication
- If a function is affine then it is both concave and convex
- If a function is both concave and convex then it is affine


# Strictly concave/convex
- Just remove the equal to from the equations to make it strict
- Strictly convex gives more guarantees for finding the minimum in some convex problems. We will see it later.

# First order conditions
Let $f: C \subseteq \R^n \rightarrow \R$ be a differentiable ($C^1$), then $f$ is convex iff
$\forall x, y \in C, f(x) + \nabla f(x)^t(y-x) \le f(y)$ 

## 1-d case

$\forall x, y \in C, f(x) + \frac{df(x)}{dx}(y-x) \le f(y)$ 

This is just the equation for the first order Taylor approximation
This is also the tangent space at the point $x$
This has to be **always below** the function

## General case

The $nabla$ is like a directional differentiation operator. With just the $nabla$ you can find the velocity along any direction
